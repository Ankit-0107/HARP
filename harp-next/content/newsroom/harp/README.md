# HARP newsroom stories

Add one `.mdx` file per story here, named after its URL slug (`my-story.mdx` → `/newsroom/my-story`).
A file whose slug matches one of the 8 placeholder entries replaces that placeholder; any other slug is added as a new story.

```mdx
---
title: "Your headline"
category: "Article"          # "Article" | "Case Study"
date: "2026-12-01"           # ISO date
author: "Full Name"
heroAssetId: "news-my-story" # image slot → put the file at public/assets/harp/news-my-story.webp
lead: "One or two sentence summary shown under the title and used for SEO."
---

Body in Markdown / MDX. Use `## Headings`, lists, **bold**, links.
```
Only verified, owner-approved content belongs here.
